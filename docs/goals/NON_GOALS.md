# PRISMA Non-Goals

**Document Identifier**: `PRISMA-NON-GOALS`  
**Status**: Standard Non-Goals  

---

## 1. What PRISMA IS NOT

- **PRISMA IS NOT an LLM**: No es un modelo probabilístico de lenguaje ni intenta entrenar redes neuronales monolíticas.
- **PRISMA IS NOT a Chatbot**: No es un sistema de conversación ni una interfaz de diálogo para usuarios finales.
- **PRISMA IS NOT a Database**: No reemplaza bases de datos relacionales, documentales ni de clave-valor.
- **PRISMA IS NOT a Graph Engine**: No es un servidor de grafos de propiedades como Neo4j ni un triplestore RDF.
- **PRISMA IS NOT an Embedding Model**: No es un modelo de representación vectorial denso.
- **PRISMA IS NOT a Single Reasoning Algorithm**: No está limitado a Prolog, Datalog o un algoritmo de razonamiento único.

---

## 2. What PRISMA CAN USE

PRISMA puede interoperar, coordinar y consumir cualquiera de las siguientes tecnologías como componentes subordinados o proyectores:

- **LLMs**: Para traducción entre lenguaje natural y sintaxis formal PL.
- **Databases**: Para persistencia física duradera de objetos de conocimiento.
- **Vector Stores**: Para índices de búsqueda semántica aproximada.
- **Graph Databases**: Para visualización y navegación de redes de conocimiento.
- **SAT Solvers & Theorem Provers**: Como motores de inferencia enchufables en tiempo de ejecución.
